How the YouTube API works

One request, end to end

  1. Pick a methodA resource + action, like videos.list.
  2. Add credentialsAPI key for public data, OAuth for anything private or any write.
  3. Choose partWhich slices of the resource to return.
  4. Get JSON backPlus nextPageToken if there's more.
  5. Pay quotaEvery call costs units, even failed ones.

Two kinds of credentials

API keyOAuth 2.0 (Connect Google account)
IdentifiesYour Cloud projectA signed-in user, with consent for specific scopes
Can doRead public data: any video, channel, playlist, public comments, searchRead private data (mine=true), write anything, use Analytics
Can't doAnything involving "me" or any changeNothing extra needed for public data
Where it goes?key=… in the URLAuthorization: Bearer … header

Scopes are the permission slips: youtube.readonly to look, youtube.force-ssl to manage comments/playlists/videos, yt-analytics.readonly for Analytics. Ask for the least you need.

Quota: the thing you'll actually run out of

  • Most methods share a pool of 10,000 units per day. Reads cost 1; writes usually 50.
  • Since June 2026, search.list and videos.insert each have their own bucket (100 calls a day by default) instead of drawing from the pool. videos.batchGetStats has its own 10,000-unit bucket.
  • Quota resets at midnight Pacific Time.
  • Invalid requests still cost at least a point. Every extra page of results costs again.
  • Video uploads got much cheaper in December 2025 (about 1,600 units down to about 100).
  • Google's response never tells you what's left. This playground keeps a local tally; the Quotas page in Cloud Console is the truth.

part and fields: ask for less

part is required on most calls and selects which sections of a resource you get (snippet, statistics, contentDetails…). Cost doesn't change with more parts, but the payload does. For finer trimming use fields, e.g. items(id,snippet/title,statistics/viewCount). Find it under Advanced in the Explorer.

Pagination

List methods return a page (maxResults, usually up to 50) and a nextPageToken. Pass it back as pageToken with the identical query to get the next slice. The Explorer shows Next/Prev buttons when tokens exist.

Cheaper patterns worth knowing

  • List a channel's videos: channels.list → relatedPlaylists.uploads → playlistItems.list. 1 unit per page instead of spending search calls.
  • Stats for many videos: videos.list?id=a,b,c… takes up to 50 IDs for 1 unit; videos.batchGetStats is the new lightweight version.
  • Search is for discovery, not for listing things you already know the ID of.

Recent changes worth knowing (from Google's revision history)

  • Nov 3, 2026: thumbnails.set supports custom thumbnails for Shorts.
  • Nov 2, 2026: uploads from unverified API projects are no longer forced to private.
  • Aug 27, 2026: public view counts now count when playback begins, across long-form, Live and Shorts.

  • Jul 2025: chart=mostPopular now returns Trending Music, Movies and Gaming.

When it goes wrong

Errors come back as JSON with error.code and error.errors[0].reason. The Explorer translates the common ones. The usual suspects: quotaExceeded (budget), insufficientPermissions (missing scope; reconnect), forbidden (not your video), accessNotConfigured (API not enabled in the Cloud project), commentsDisabled (owner turned them off).
